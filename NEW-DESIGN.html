초보자를 위한 자동 개발 레일

ZEROSHOT-CODEX는 아이디어를 바로 코드로 보내지 않습니다. 먼저 사용 목적, 화면 범위, 데이터, 배포 조건을 확정하고 그 결과를 사람이 읽을 수 있는 인터랙티브 설계서로 고정합니다.

USER개발을 처음 시작하는 사람
JOB앱 아이디어를 안전한 빌드 작업으로 변환
OUTPUT질문이 끝난 설계서와 실행 가능한 빌드 큐

01. DESIGN LOOP

사용자가 만들 앱을 적으면 에이전트는 바로 코딩하지 않고, 먼저 누락된 결정을 찾아냅니다. 질문은 기능 범위, 사용자 입력, 저장 방식, 첫 화면, 배포 목표처럼 되돌리기 어려운 것에만 집중합니다.

02. REQUIRED QUESTIONS

  • 앱의 첫 성공 상태는 무엇인가?
  • 로그인과 저장이 필요한가, 아니면 로컬에서 끝나는가?
  • 첫 버전에 꼭 필요한 화면은 몇 개인가?
  • 빌드 결과는 웹앱, 모바일 시안, 대시보드 중 무엇인가?

03. HTML SPEC

모든 답이 모이면 설계서는 문서가 아니라 조작 가능한 HTML로 반환됩니다. 섹션을 펼쳐 화면 흐름을 확인하고, 질문 답변이 어떤 빌드 조건으로 바뀌었는지 바로 볼 수 있습니다.

04. BUILD HANDOFF

사용자가 끝까지 스크롤하거나 하단의 긴 BUILD 버튼을 누르면 설계서는 잠기고 BUILD 탭으로 넘어갑니다. 이 시점부터 에이전트는 질문을 멈추고 파일 생성, 테스트, 미리보기 확인으로 모드를 바꿉니다.

05. GUARDRAILS

  • 불확실한 요구사항은 빌드 전에 질문으로 되돌립니다.
  • 초보자가 이해할 수 있게 기술 선택 이유를 한 줄로 남깁니다.
  • 빌드 실패는 원인, 수정, 재시도 로그로 분리해 보여줍니다.
